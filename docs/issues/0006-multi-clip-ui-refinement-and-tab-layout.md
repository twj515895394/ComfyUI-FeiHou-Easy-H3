# Issue 0006: 优化 MultiClip 素材大组件前端渲染（隐藏冗余原生提示词、美化 Tab 栏与容器高度自适应）

## 父问题
docs/issues/0003-multi-clip-tab-ui-component.md

## 要构建什么
针对 Node 2 (`FeiHouEasyH3MultiClip`) 在 ComfyUI 浏览器画布上呈现的双重提示词框、Tab 换行折断与高度截断等 UI 体验缺陷进行全面重构与优化：
1. **隐藏原生冗余提示词输入框**：在 `web/feihou_easy_h3_multi_clip.js` 中动态将 LiteGraph 默认绘制的 `global_prompt` 多行文本框设为不可见（隐藏或折叠高度为 0），提示词输入统一收口在自定义 DOM 面板内部，消除“双胞胎输入框”视觉混乱；
2. **Tab 栏单行排版与防误触优化**：
   - 为 Tab 栏增加弹性布局与横向滚动（`overflow-x: auto`）或标题最大宽度截断（`max-width: 140px; text-overflow: ellipsis; white-space: nowrap;`）；
   - 在 Tab 上增加完整提示气泡（`title` 属性），彻底消除“分镜 3”断头掉落到第二行的丑陋换行；
   - 增加关闭按钮 `✕` 与文字之间的间隔，增加按钮悬浮放大与防误触提示；
3. **节点默认尺寸自适应**：将工作流中 Node 2 的推荐渲染尺寸从 `[580, 600]` 扩至 `[600, 760]`，让 9 图片 + 3 视频 + 3 音频素材卡槽舒展展开，彻底告别生硬的内嵌双重滚动条；
4. **精细化参数对齐**：优化分镜 Tab 勾选覆盖时的秒数、步数、转折步输入框的垂直居中与标签对齐。

## 验收标准
- [x] 节点 2 上方不再出现原生的灰色多行文本框，画布上仅保留一个精美统一的提示词编辑区
- [x] Tab 标签栏在包含 3 个以上分镜时整齐单行排列，分镜名称不产生生硬多行断裂
- [x] 关闭按钮 `✕` 具备安全间距且不干扰 Tab 切换
- [x] 素材卡槽区域在默认节点高度下完整可见，无需拖拽内部垂直滚动条即可操作卡槽
- [x] 用户在 DOM 内部输入提示词或切换分镜，与后端 `global_prompt` 和 `multi_clip_data` 实时双向同步无丢失
