## 刷新丢线：最可能的机制

当前接线不是稳定的 ComfyUI 原生口，而是三套东西叠在一起：

1. Python `INPUT_TYPES["hidden"]` 里的 `image_N` / `video_N` / `audio_N`（刚从 `optional` 挪过来，避免 Vue 排高度）
2. 前端启动时 **删掉 live sockets**：`ensureMediaSlotInputs` 把已接线转成虚拟线再 `removeInputSlot`
3. 虚拟线存在 `node.properties.minimax_h3_virtual_media_links`（`LINKS_PROP`）

刷新后必炸的一行：

```js
// setupMainNodeFrontend
delete node.properties[LINKS_PROP];
```

然后 `ensureMediaSlotInputs` 再把原生口删掉。原生 ComfyUI link 早已在 `convertNativeMediaConnection` 里被 disconnect。刷新后：虚拟线没了，原生口也没了，画面上的线必然消失。

`graphToPrompt` 现在只在 `mediaSlotSource(...).sourceNode` 仍在图里时才写 `[sourceId, slot]`。刷新后 source 对不上就当没接线。

相关函数（都在 `web/feihou_easy_h3_ui.js`）：

- `ensureMediaSlotInputs` — 删 live `image_N` 口
- `convertNativeMediaConnection` — 原生线 → 虚拟线，并 disconnect
- `setupMainNodeFrontend` — **无条件 delete LINKS_PROP**
- `mediaSlotSource` — 有 live 口且已断开则忽略虚拟线缓存；无 live 口才读虚拟线
- `patchGraphToPrompt` — 只在 `wired.sourceNode` 存在时重建 prompt 连线
- `pruneTransportInputs` / `isTransportInputName` — 从 Vue schema 去掉 `image_N` 等，防止排成控件

后端仍能吃接线 tensor：`FeiHouEasyH3._collect_media` 里非字符串 payload 直接当 IMAGE/VIDEO/AUDIO。点击上传走 `_load_image_file`（Pillow），不要再走官方 `LoadImage`/`VideoFromFile`。

## 禁区：节点无限拉长（已发生 2 次）

症状：主节点变成一条很高的空紫条，只剩左上 `h3_bundle`、右上 `model` / `h3_context`，画廊和提示词全没了。

两次触发都是同一类改动：

1. 把 `image_N` / `video_N` / `audio_N` 从「前端藏起来」改成 **Vue 可见的 optional 控件**（15 个 IMAGE 口被排成空白行）
2. `feihou_easy_h3_ui.js` 语法被改坏，扩展没挂上，Vue 按默认 schema 画节点，同样空长条

**以后改接线，禁止：**

- 把 `image_N` / `video_N` / `audio_N` 放回 `INPUT_TYPES["optional"]` 当普通控件
- 从 `isTransportInputName` 里拿掉 `image|video|audio_N`（否则 Vue schema 会再画出这些口）
- 停掉 `ensureMediaSlotInputs` 的删口却不改高度折叠（`collapseInflatedMediaSlotHeight` 期望这些口不占 computeSize）
- 改 `feihou_easy_h3_ui.js` 后不跑 `node --check web/feihou_easy_h3_ui.js`

当前防拉长的正确形态：

- Python：这些槽在 **`hidden`**，不在 optional
- 前端：schema prune + live socket 删除 + 画廊格子自定义命中/画线
- `installMediaSlotGeometry` 的 `computeSize` 会临时滤掉 media slot 再算高度

修「刷新丢线」时，不要为了保留 ComfyUI 原生 link 就把 15 个口重新暴露给 Vue。要保留原生 link，必须同时保证：口 `hidden`、不进 widget 布局、`computeSize` 不计这些口。
